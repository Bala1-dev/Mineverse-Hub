# Project Status

## Public Open Core

Mineverse Open Core v0.1.0 remains a public beta prerelease. Its Unreal Engine
5.6 plugin exposes the documented interfaces, schemas, extension contracts,
and generic validation structures described in [OPEN_CORE_SCOPE.md](../OPEN_CORE_SCOPE.md).
The v0.1 public API remains frozen under [API_STABILITY.md](API_STABILITY.md).

## Mark 13 Locomotion

Mark 13 locomotion is provisionally accepted for demo progression. This
acceptance is limited to demonstration planning and community playtesting; it
does not mean the system is production-ready, production-approved, or included
in the public open-core plugin. Feedback should be limited to safe, sanitized
observations suitable for public disclosure.

## Planned Work

The Universal Operator Action Framework is planned. No delivery date,
implementation status, or public API commitment is made here. Any future
public material requires review against the open-core scope and security
boundaries.

GPU-assisted validation is restricted by engineering policy. This statement
records a policy restriction only; it does not claim that GPU-assisted
validation has been implemented, run, or verified.

## Engineering Doctrine

Mineverse uses a security-first engineering doctrine: minimize public attack
surface, preserve auditable boundaries, validate only approved public
contracts, and keep credentials and sensitive operational details private.
See [SECURITY.md](../SECURITY.md) for reporting guidance. Apache-2.0 applies
only to approved public material in this repository; the boundaries in
[OPEN_CORE_SCOPE.md](../OPEN_CORE_SCOPE.md) remain controlling.
