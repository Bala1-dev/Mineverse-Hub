# Community Playtesting

Community playtesting gathers public, sanitized observations that can support
demo progression. Mark 13 locomotion is provisionally accepted for demo
progression only. Playtesting is not production validation or approval and
does not make the locomotion system production-ready.

## What to Share

Share concise, reproducible observations that are safe for a public issue:

- a general description of the observed behavior
- steps to reproduce using an approved public demo build
- expected and observed results
- broad platform or build information when safe to disclose
- whether the issue is repeatable

Do not attach project files, binary assets, full logs, screenshots containing
private information, or material from private Mineverse systems.

## Do Not Share

Never include credentials, tokens, private endpoints, customer data, personal
data, full machine identifiers, private paths, unpublished security designs,
exploit details, production configuration, or private implementation details.
Do not use community testing to probe production systems or restricted
components. Report sensitive security findings through the private channel
described in [SECURITY.md](../SECURITY.md), not a public issue.

Use the [community feedback form](../.github/ISSUE_TEMPLATE/community-feedback.yml)
for sanitized feedback. Maintainers may close reports that contain sensitive
material without reproducing it publicly.

## Scope and Status

Playtesting comments inform demo iteration and do not guarantee acceptance,
fixes, or release timing. The Universal Operator Action Framework remains
planned work. GPU-assisted validation restrictions are policy; this guidance
does not claim that GPU-assisted validation is implemented or verified.

All contributions remain subject to the repository's Apache-2.0 and
open-core boundaries. See [OPEN_CORE_SCOPE.md](../OPEN_CORE_SCOPE.md) and
[CONTRIBUTING.md](../CONTRIBUTING.md).
