# Contributing

Thank you for helping improve Mineverse Open Core.

This repository accepts public contributions only within the approved
open-core boundary:

- framework interfaces and extension contracts
- public schemas and documentation
- sanitized examples
- approved generic validation components

Do not submit production gameplay, Oracle infrastructure, UNIT economy
implementations, operational security systems, premium Fab modules, content
assets, private configuration, credentials, endpoints, or unpublished commercial
Mineverse technology.

By submitting a contribution to this repository, you agree that the
contribution is licensed under Apache-2.0 unless you clearly mark it as "Not a
Contribution." You must have the right to submit the material.

Before opening a pull request:

- keep changes inside the approved public scope
- do not copy private repository history
- do not include generated Unreal folders or asset payloads
- add SPDX and copyright headers to source files
- explain any Unreal Engine public API dependency
- run available validation for changed source

Apache-2.0 does not grant branding or trademark rights beyond identifying the
origin of the project.
